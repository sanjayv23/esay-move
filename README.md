### **esay-move**

**A Simple Moving Company Landing Page**

This repository contains the source code for a basic, static website designed to serve as a landing page for a moving company. The project is built using fundamental web technologies and includes images relevant to a moving service, such as a moving van, a couple, a family, and a dog, to create a welcoming and relatable user experience.

---

### **Features**

* **Static HTML:** The core structure of the website is built with HTML5.
* **CSS Styling:** All styling is managed with a separate CSS file.
* **Responsive Design:** (Presumed) The design is likely structured to look good on various devices.
* **Relevant Imagery:** Includes several images that visually represent the service offered.

---

### **How to Use**

To view this website, you only need a modern web browser. Simply open the **`index.html`** file in your browser, and the page will render. There is no need for a web server or any complex setup.
